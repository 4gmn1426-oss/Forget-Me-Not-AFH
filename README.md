# Forget Me Not Adult Family Home Website

This package is intentionally flat, so it is easier to upload through the GitHub website on a Chromebook.

## Files to upload to GitHub
Upload every file in this folder:

- `index.html`
- `main.jsx`
- `styles.css`
- `logo.png`
- `package.json`
- `vite.config.js`
- `README.md`

Do not upload the ZIP file itself.

## Vercel settings

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Editing

- Website wording and sections: `main.jsx`
- Colors and design: `styles.css`
- Logo image: `logo.png`
