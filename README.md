# Forget Me Not Adult Family Home Website

This is the launch-ready website package.

## How to make it live for free

1. Create a free GitHub account: https://github.com/signup
2. Create a free Vercel account: https://vercel.com and sign in with GitHub.
3. In GitHub, create a new repository named `forget-me-not-website`.
4. Upload all files from this folder into that repository.
5. In Vercel, click **Add New Project** and import the GitHub repository.
6. Keep the default build settings:
   - Framework: Vite
   - Build command: npm run build
   - Output directory: dist
7. Click **Deploy**.

## How to edit later

Most wording is in `src/main.jsx`.
Colors and visual styling are in `src/styles.css`.

Replace placeholder phone, email, location, and photos before sharing widely.
